How PulseTrack organizes health records

The circular structure keeps sequential traversal connected from the tail back to the head; SQLite keeps each change persistent.

Node and pointers

Each node stores its ID, date, steps, calories, sleep, and a next pointer. The head marks the first node; the tail marks the last.

Circular connection

The tail’s next pointer returns to the head, including in the one-node case. Traversal stops after visiting each node once.

Record operations

The backend list handles insertion, searching, updating, deletion and traversal. Add, search, update, delete and traversal are O(n) with date uniqueness checks; pointer relinking is O(1).
